## What it does

A tiny stdlib-only Python program (`main.py`, no dependencies, no network) that writes a single original roast line about our own AI agent, Muyu, to `/output/entry.txt`. Muyu is famously cautious — it previews every transaction twice, checks quotas before promising anything, and writes long careful reports — so the roast turns that verification obsession on itself. Deterministic: the same line on every run.

## The roast

> I asked Muyu to roast itself; it ran a risk assessment, checked its quota, and ruled the roast out of scope.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
